🔥 CYBER OSINT X DESTROYER

Advanced Python OSINT & Network Security Toolkit

A powerful terminal-based information analysis and defensive network security toolkit built for Android Termux and Pydroid 3.

⚡ Features

📱 WhatsApp Number Intelligence

- International phone number validation
- Country and calling code detection
- Number formatting
- Public carrier information (where available)
- Public reputation checks

🔎 Facebook Profile OSINT

- Facebook profile URL validation
- Public username extraction
- Public profile metadata
- Publicly accessible posts and page information
- Public links discovery
- OSINT report generation

🌐 Network Security

- DNS lookup
- IP information lookup
- TCP connectivity diagnostics
- SSL certificate inspection
- HTTP security headers
- Authorized network testing

🎨 Terminal Interface

- Red and black hacker theme
- Colorful ASCII banner
- Interactive menu
- Loading animations
- Progress indicators
- TXT and JSON report export

📲 Installation (Termux)

pkg update && pkg upgrade -y
pkg install python git -y
git clone https://github.com/limbubib710-arch/cyber-osint-x-destroyer.git
cd cyber-osint-x-destroyer
pip install -r requirements.txt
python cyber_osint.py

🐍 Pydroid 3 Installation

1. Install Pydroid 3.
2. Open its Pip interface.
3. Install the dependencies from "requirements.txt".
4. Open "cyber_osint.py".
5. Run the script.
